2026年9月21日—9月27日学习周报

一、本周学习内容

9月21日

本日主要学习 Python 编程基础知识，按照 Python 教程系统学习前 11 章内容。重点学习 Python 的基本语法、变量与数据类型、条件判断、循环、函数以及数据结构等内容，为后续学习深度学习相关知识以及阅读项目源码打下基础。

9月22日

继续学习 Python 前 11 章内容，对前一阶段的知识进行进一步巩固。重点学习了 Python 面向对象编程相关内容，包括类、继承和封装等，同时结合代码对前面学习的基础语法进行综合理解。通过本次学习，对后续阅读 PyTorch 和 R-MSFM 项目源码所需要的 Python 基础知识有了进一步掌握。

9月23日

开始进行 R-MSFM 项目的本地复现工作。根据项目官方文档对运行环境和项目依赖进行配置，并安装 Linux 双系统，为后续运行和调试 R-MSFM 项目建立实验环境。同时开始熟悉 R-MSFM 的项目结构、运行方式以及模型文件的组织形式。

9月24日

继续进行 R-MSFM 项目的环境配置和运行调试。针对项目运行过程中出现的环境、依赖以及模型路径等问题进行排查，进一步熟悉 test_simple.py 单图推理脚本的运行方式，并检查输入图片、模型文件以及相关配置之间的对应关系。

9月25日

完成 R-MSFM test_simple.py 单图推理脚本的调试，成功实现单张图片的推理。通过本次实践，进一步了解了深度学习项目加载预训练模型、读取输入图像、进行模型前向计算以及生成推理结果的基本流程，同时熟悉了 Linux 环境下 Python 深度学习项目的运行和调试方法。

9月26日

开始系统学习 PyTorch 基础知识。主要学习了 PyTorch 官方教程中的 Tensor、Dataset 和 DataLoader、Transforms、构建神经网络、自动微分、模型参数优化以及模型保存与加载等内容。

通过学习进一步理解了 Tensor 数据表示、数据加载与预处理、神经网络模型构建、前向传播、损失函数、反向传播、梯度计算和优化器更新参数等基本概念，并对 PyTorch 从数据处理到模型训练、保存和推理的完整流程形成了初步认识。

9月27日

搭建个人学习博客，用于整理研究生阶段的学习过程以及后续周报。使用 Hugo 完成博客的创建和基本配置，并对 Hugo 的运行方式、主题配置等内容进行了学习。同时将博客与 GitHub 进行连接，为后续上传周报、学习笔记以及项目复现记录做好准备。

二、本周学习总结

本周主要围绕 Python 基础、R-MSFM 项目复现、PyTorch 基础以及学习资料整理四个方面开展学习。

首先通过 Python 前 11 章的学习进一步巩固了编程基础；随后根据 R-MSFM 项目文档完成 Linux 双系统以及相关运行环境的配置，并成功跑通 test_simple.py 单图推理脚本，实现了 R-MSFM 的初步本地复现。

在此基础上开始学习 PyTorch 官方基础教程，对 Tensor、数据加载、数据预处理、神经网络构建、自动微分、模型参数优化以及模型保存与加载等内容进行了系统学习。通过这些内容的学习，对深度学习模型从数据输入、模型计算、损失计算、反向传播到参数更新的基本过程有了更加清晰的认识。

最后搭建 Hugo 博客并连接 GitHub，为后续整理学习资料和记录科研进展建立了持续性的记录平台。

三、下周学习计划

下周将以 R-MSFM 项目的源码和算法分析作为主要学习内容。在已经成功运行 test_simple.py 单图推理的基础上，进一步分析该脚本的完整执行流程，重点了解模型加载、图像预处理、网络前向传播以及最终推理结果生成的具体过程。

同时结合本周学习的 PyTorch 基础知识，对 R-MSFM 中 Encoder、Decoder、Tensor 运算以及模型推理过程进行进一步分析，逐步理解项目的网络结构和核心代码实现。

此外，继续学习卷积神经网络以及深度学习相关基础知识，并将学习过程中整理的内容持续更新到 Hugo 博客中，形成较为完整的学习笔记和项目复现记录。
