2026年9月21日—9月27日学习周报

一、本周学习内容

9月21日

本日主要学习 Python 编程基础知识，学习了《Python编程：从⼊门到实践》前8章。重点学习 Python 的基本语法、变量与数据类型、条件判断、循环、函数等内容。

9月22日

继续学习 Python 基础，对前一阶段的知识进行进一步巩固。重点学习了 Python 面向对象编程相关内容，包括类、继承和封装等，同时结合代码对前面学习的基础语法进行综合理解。

9月23日

开始复现 R-MSFM 项目。根据项目文档制作ubuntu安装盘，安装ubuntu系统

9月24日

参照R‑MSFM零基础教程，完成NVIDIA驱动、CUDA、cuDNN、PyTorch环境配置以及Anaconda虚拟环境搭建。创建rmsfm专用conda虚拟环境，安装适配版本Python、PyTorch及项目所需依赖库，验证GPU CUDA可用性，为后续项目推理调试准备完整运行环境。

9月25日

调试 R-MSFM 单图推理脚本，检查测试图片、预训练模型和运行参数。经过调整后成功运行 test_simple.py，完成单张图片的推理。

9月26日

学习 PyTorch 官方基础教程，搭配chatgpt讲解。主要学习 Tensor、Dataset 和 DataLoader、Transforms、神经网络构建、自动微分、模型参数优化以及模型保存与加载。重点学习 Tensor 操作、数据加载、nn.Module、loss.backward()、优化器以及 state_dict() 等内容。

9月27日

使用 Hugo 搭建个人学习博客，学习 Hugo 项目结构,完成博客本地运行、主题配置以及 GitHub 连接，并测试文章提交和推送流程，用于后续记录周报。

二、本周学习总结

本周完成了《Python编程：从⼊门到实践》的前11 章学习，也就是书中第一部分基础知识的学习，掌握 Python 基础语法、数据结构、函数以及类等内容；完成 windows/Linux 双系统和运行环境配置，并成功运行 test_simple.py 完成单图推理；学习 PyTorch 基础教程，了解数据处理、模型构建、自动微分、参数优化以及模型保存加载流程；同时完成 Hugo 博客搭建并连接 GitHub。

三、下周学习计划

下周要学习《Python编程：从⼊门到实践》中的第二部分项目，从项目中巩固学习到的内容。而pytorch是下周重点学习内容，这周仅仅是对pytorch项目的流程做了粗略的了解，简单学习了文档中的基础知识。下周要重点回顾这方面的内容，并结合文档中提供的具体代码示例来理解学习。
